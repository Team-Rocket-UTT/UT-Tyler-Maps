NavigationManager

class NavigationManager(activity: MapActivity, mapView: MapView, container: FrameLayout, isDark: Boolean)

Manages indoor navigation, route calculation, and navigation UI panels.

This class is responsible for calculating directions between spaces (or from the user's current coordinate to a space), rendering navigation paths on the map, displaying turn-by-turn instruction markers, and managing the various bottom-sheet UI panels (info panel, route plan panel, and active navigation panel).

Supports both coordinate-based navigation (from the user's live IndoorAtlas position) and space-to-space navigation (when the user selects an origin room). Accessible route options are forwarded to the Mappedin directions API when enabled.

See also

MapActivity.navLauncher

for how navigation is triggered from the navigation screen
