MapActivity

class MapActivity : AppCompatActivity, IALocationListener

Main activity for the UT Tyler Maps application.

This activity is responsible for rendering an interactive indoor map using the Mappedin SDK, tracking the user's real-time indoor position via IndoorAtlas, and providing features such as room search, turn-by-turn navigation, floor switching, and space highlighting.

Implements IALocationListener to receive indoor location updates from IndoorAtlas.
