UIBuilder

class UIBuilder(activity: MapActivity, isDark: Boolean, mapView: MapView)

Builds and manages all UI elements for the MapActivity programmatically.

This class constructs the full view hierarchy without XML layouts, including the map container, loading overlay, search bar with Material SearchView, category filter chips, floor switcher, floating action buttons (location and navigation), and the bottom navigation bar. It also handles category-based room filtering by highlighting matching spaces on the map and dimming non-matching ones.

All UI elements are theme-aware, adapting colors and styling based on isDark.
