FloorManager

class FloorManager(mapView: MapView)

Manages the available building floors and handles switching the displayed floor on the map.

This class maintains the list of all Floor objects retrieved from the Mappedin map data, tracks which floor is currently being displayed, and provides a mapping between IndoorAtlas floor level numbers and Mappedin floor names. A callback onFloorChanged is invoked whenever the displayed floor changes, allowing other components (such as the blue dot) to react.

See also

MapActivity.onMapReady

where floors are loaded and the floor switcher UI is built

MapActivity.syncBlueDotVisibility

which reacts to floor changes
