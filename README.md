# UT-Tyler-Maps
Mobile app for navigating UT Tyler using MAppedIN SDK for maps and IndoorAtlas for live indoor positioning.
The app allows users to find rooms and get directions.

## Features
- Search for rooms.
- Provide directions and estimated time of arrival.
- Show points of interest on map.
- Location tracking using IndoorAtlas.

## Tech Stack
- Android Studio (Kotlin)
- Mappedin Android SDK
- Indoor Atlas SDK

## Installing
1. Clone the repository:
   ```
   git clone https://github.com/Team-Rocket-UTT/UT-Tyler-Maps.git
   ```
3. Open the project in Android Studio.
4. Add your API keys to the .env file.
5. Build and run the app.
